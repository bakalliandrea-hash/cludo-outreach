Import prospects into this campaign

Accepted: the contacts.json generated with Claude, a CSV with the columns first_name, last_name, email, organisation, title (optionally area, website, linkedin, city, subject, body; commas, semicolons or tabs), or a backup file exported from this page. Prospects are matched by email address, so importing the same file twice updates rather than duplicates. A backup restores the sent, reply and bounce history as well.

When a prospect has no area, it is guessed from the job title (web, communication or IT) and the card is marked for review.
